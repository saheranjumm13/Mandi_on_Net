# Mandi_on_Net

Mandi_on_Net is a simple grocery shopping website designed using **HTML, CSS, and JavaScript**. The website provides a clean interface for browsing fresh and organic products with shopping cart, search, login, and product sections.

## Features

* 🥬 Fresh and organic products
* 🛒 Shopping cart
* 🔍 Product search
* 👤 Login form
* 🚚 Free delivery section
* 💳 Easy payment section
* ⭐ Product ratings
* 📱 Responsive design
* 🖼️ Product image slider

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Swiper.js

## Website Sections

* Home
* Features
* Products
* Categories
* Reviews
* Blogs
* Shopping Cart
* Login

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the Fithub grocery shopping website.
